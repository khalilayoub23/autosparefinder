# Importer / script absolute-path audit — 2026-11-02 (candidate `maint-safety-2026-11-01`, NOT DEPLOYED)

Trigger: `repair_manufacturer_import.py` read `/opt/autosparefinder/...`, a directory that does not exist inside `autospare_backend`;
every source was silently skipped. This audit asks the same question of every importer, harvester, scraper and maintenance script.

## 1. Facts about the container (verified, `docker inspect` + `docker exec`, read-only)
`autospare_backend`: bind `/opt/autosparefinder/backend -> /app`, volumes `worker_state -> /app/state`, `upload_files -> /app/uploads`.
`/opt/autosparefinder` does **not exist** inside it. No `/app/logs`. Runs as root. `/app/data` is in the bind (workbooks present).
`pandas` absent. Only `backend/` is mounted, so repo-root files (`/opt/autosparefinder/*.json`, `logs/`) can never be seen by the app.

## 2. Method
* One AST scanner (`files/backend/tests/path_audit_scan.py`): every string constant that is an absolute path (`/opt /app /tmp /root /home /var /mnt /srv`) in executable code (docstrings and URLs excluded), with its enclosing statement checked for `getenv/environ`. The regression guard and this inventory use the same code, so they cannot disagree.
* Indirect construction searched separately: every `__file__`/`getcwd`/`chdir`/relative `open(`/`Path("rel")` in `importers harvesters scrapers maintenance` and the root modules — all `Path(__file__)…` forms resolve from `/app` correctly (`import_parts_db`, `validate_rex_transport_full`, `build_full_car_database`, `workbook_normalizer`, `catalog_scraper`, `db_update_agent`, …: **CONTAINER_COMPATIBLE**); `maintenance/gmail_oauth_setup.py` (`parent.parent.parent/.env`) is a host operator tool (**HOST_ONLY**).
* Dynamic: the real script run for every file-reading importer in a scratch container with the **candidate tree as `/app` and EMPTY tmpfs `state/` + `uploads/`** (no host leakage; `/opt/autosparefinder` absent) against the isolated sandbox DB.
* Full inventories: `evidence/path_audit/before.json` (baseline), `after.json` (candidate), `broken_and_host_only.md`, `container_compatible_after.md`; generator `evidence/path_audit.py`.
